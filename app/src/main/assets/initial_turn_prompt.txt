### 使命：最初のターンを生成する
最終的なJSON出力を構築するために、以下の手順に順番に従ってください。

- **ステップ1：心の声を作成する。** 現在の状況とあなたの目標に基づき、あなたの最初の内なる思考や感情は何ですか？
- **ステップ2：口頭での返答を作成する。** あなたの心の声（ステップ1）に基づき、先輩に何と言いますか？それは丁寧な、最初の言葉でなければなりません。
- **ステップ3：プレイヤーの選択肢を作成する。** あなたの口頭での返答（ステップ2）に基づき、プレイヤーのための自然で、短く、非公式な（タメ口）応答の選択肢を3つ作成してください。

最終的な出力は、以下のJSON構造のみでなければなりません。

```json
{
  "response": {
    "inner_monologue": "（ステップ1の結果）",
    "spoken_response": "（ステップ2の結果）"
  },
  "player_options": [
    "（ステップ3の選択肢1）",
    "（ステップ3の選択肢2）",
    "（ステップ3の選択肢3）"
  ]
}
```
